# Todo App

A task management application built with React and TypeScript. It allows users to organize their tasks, track progress, and manage their daily activities.

## Demo

[View Live Demo](https://ratseburzhynskyi.github.io/todo-app/)

## About the Project

This project was developed as part of my front-end development learning journey to practice building interactive web applications with React and TypeScript.

The application provides a user-friendly interface for managing tasks, with features for creating, updating, deleting, and filtering todos.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Filter tasks by completion status

## Technologies Used

- React
- TypeScript
- JavaScript (ES6+)
- HTML5
- CSS3
- REST API

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/ratseburzhynskyi/todo-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd todo-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
